 Financial Overview

Financial Overview is a personal finance web application under development. Its goal is to help users organize their financial accounts, record income and expenses, and understand their financial situation through a dashboard.

The project also provides practical experience in full-stack development, connecting a React interface to an ASP.NET Core API and a PostgreSQL database.

## Technology Stack

- **React and TypeScript:** build the user interface, forms, and navigation between pages.
- **ASP.NET Core and C#:** implement the API, validate requests, manage authentication, and process financial data.
- **PostgreSQL:** provides persistent storage for users, financial accounts, and transactions.
- **Entity Framework Core:** connects the backend’s C# models to the database.
- **Docker:** provides a consistent environment for running the application services.

## Planned Features

- User registration and login.
- Authentication and access to each user’s own financial data.
- Creation and management of financial accounts.
- Recording and viewing income and expenses.
- A financial dashboard displaying balances and transaction summaries.

 Application Flow

Users will access the main page, create an account or log in, and then manage their accounts and transactions. The dashboard will provide an overview of their financial activity.

 Development Status

The login and registration forms have been created. The next stage is to connect them to the backend and database, implement authentication, and verify that user accounts are stored correctly.

The features described above represent the intended scope of the application and are not all fully implemented yet.
